# แผนก่อนทดลอง 5–6 พฤศจิกายน 2569

1. **23–25 ต.ค. ฐานเผยแพร่:** source เดียว, 4 skills, MCP, SDK/HTTPS tests, policy pages, ZIP และ portal scan ข้อกฎหมายรอเจ้าของรับรอง
2. **26–29 ต.ค. ทดสอบผ่าน host จริง:** ทดลอง 5 กรณีบวก 3 กรณีลบ ตรวจคำตอบ ใบงาน เวลา วัสดุ การอ้างอิง และบัญชีที่จะใช้จริง แยกจาก unit tests
3. **30 ต.ค.–2 พ.ย. แก้และตรึงรุ่น:** แก้ตามหลักฐาน ส่งแก้หากผู้ตรวจขอ เตรียม fallback กระดาษและ prompt อย่าผูกวันงานกับเวลารออนุมัติ
4. **3–4 พ.ย. ซ้อม:** ใช้เครื่อง บัญชี และเครือข่ายที่จะใช้ในงาน ตรวจเส้นทางเมื่อ quota หมดหรือ MCP ล่ม
5. **5–6 พ.ย. ทดลอง:** ครูทำชิ้นงานและเลือก รับ/แก้/ไม่รับข้อเสนอ บันทึกเหตุผลและปัญหาการเข้าถึงโดยไม่เก็บข้อมูลเด็ก
6. **หลังงาน:** เพิ่ม skill หรือ QA แยกตัวเมื่อพบช่องว่างและข้อผิดพลาดซ้ำจริง ไม่เรียกผู้ตรวจเพิ่มทุกคำตอบ
