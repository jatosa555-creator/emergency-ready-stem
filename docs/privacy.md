# Privacy — Emergency-Ready STEM

Effective 23 October 2026. Publisher: CHANON PHAJUNDA.

This plugin helps teachers design learning. The public MCP searches and reads a fixed library of original guidance and synthetic examples. It has no login, student database, write tool, private Drive access, automatic follow-up or cross-chat memory. Search accepts short topics; do not send student names, contact information, diagnoses, trauma histories or private school documents.

The MCP receives the tool arguments sent by the host. Its application code does not save search queries, request bodies or personal profiles, and does not log tool arguments. Netlify processes requests and may retain operational metadata such as IP addresses, timestamps and errors under its own policies and retention controls. We do not promise zero infrastructure logging. The chat host processes conversation content under its own policies; this plugin does not control host retention, account access or quotas.

GitHub hosts public project files and issues. Do not put personal information in public issues. For support or privacy requests, use [https://github.com/jatosa555-creator/emergency-ready-stem/issues](https://github.com/jatosa555-creator/emergency-ready-stem/issues), initially describing only the issue type. Do not publish the sensitive material itself. No student data is required to use the plugin.

Changes to this policy will be dated in this repository.
