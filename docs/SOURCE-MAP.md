# Source map

- `plugin/skills/`: canonical four workflows adapted from the owner's local v0.3.0.
- `remote-mcp/data/catalog.json`: canonical public knowledge. Ten original project guidance items and two synthetic examples. No third-party checklist reproduction or private Drive text. `knowledge/ER-*.md` are generated readable views.
- Packaged references: original compact fallback guidance for this project.
- MCP technical deployment pattern: adapted from the owner's Teacher Co-Growth repository, with separate educational content, data and publication authorization.
- Python structural validators: preserved from v0.3.0; they do not validate pedagogy, truth or outcomes and do not run automatically on teacher accounts.
- `docs/submission/`: intended review cases and actual evidence/status. Intended behavior is not a recorded host result.
- `dist/`: generated clean ZIP and receipts, ignored by Git. Development handoff ZIPs are not review packages.

GitHub hosts public source and policy/support pages. Netlify serves a fixed project snapshot. No live Drive connection, runtime instruction fetch, private record access or cross-chat memory is claimed.
